# تحدّي الثانية 🎯⏱️

لعبة جوال (أندرويد) تعتمد على إحساس اللاعب بالوقت: يظهر رقم مستهدف (مثل 3.00)، يضغط اللاعب "ابدأ" فيبدأ العدّ **دون أن يراه**، وعليه أن يضغط "توقف" في اللحظة التي يشعر أنها تطابق الرقم تمامًا. المطابقة التامة فقط هي التي تمنح نقطة.

اللعبة مبنية بتقنية **Capacitor** (ويب مغلّف داخل تطبيق أندرويد أصلي)، تعمل **بالكامل بدون إنترنت**، وتُبنى تلقائيًا إلى ملف APK عبر **GitHub Actions**.

---

## 📁 هيكل المشروع

```
├── package.json                  # تبعيات Capacitor
├── package-lock.json
├── capacitor.config.json         # معرّف التطبيق، اسمه، ألوان الخلفية
├── .gitignore
├── .github/workflows/
│   └── build-android.yml         # يبني ملف APK تلقائيًا عند كل push
├── scripts/
│   └── customize-android.js      # يطبّق الأيقونة الشفافة + شاشة البداية + يزيل صلاحية الإنترنت
├── resources/
│   ├── icon/                     # الأيقونة بخلفية شفافة 100% بجميع الأحجام
│   └── splash/                   # شاشة البداية الأصلية (Android) بجميع الأحجام
├── www/                          # التطبيق نفسه (HTML/CSS/JS)
│   ├── index.html
│   ├── css/style.css
│   ├── js/app.js                 # كل منطق اللعبة
│   └── assets/
│       ├── images/logo.png
│       └── audio/dwarven-mine.mp3
└── verify/                       # اختبارات آلية (اختيارية، لا تدخل في التطبيق النهائي)
    ├── numbers.txt                # نسخة مرجعية من قائمة الأرقام العشوائية المُتحقق منها
    ├── smoke_test.js
    └── scoring_test.js
```

> **ملاحظة مهمة:** مجلد `android/` **غير مرفوع** عمدًا لإبقاء المستودع خفيفًا. تقوم أداة GitHub Action ببنائه من جديد تلقائيًا في كل مرة عبر أمر `npx cap add android`، ثم تُطبّق عليه الأيقونة وشاشة البداية والموسيقى.

## 🚀 كيف تحصل على ملف APK

1. ارفع هذا المشروع كما هو (بنفس المسارات) إلى مستودع GitHub جديد.
2. بمجرد أن يصل الرفع إلى فرع `main`، ستبدأ أداة **GitHub Actions** بالعمل تلقائيًا (يمكنك أيضًا تشغيلها يدويًا من تبويب Actions → Build Android APK → Run workflow).
3. بعد انتهاء البناء (حوالي 3-5 دقائق)، افتح التبويب **Actions** → اختر آخر تشغيل ناجح → في أسفل الصفحة ستجد **Artifacts** باسم `tahaddi-al-thania-apk` — حمّله وفكّ ضغطه لتحصل على ملف `app-debug.apk` الجاهز للتثبيت.

## 🎨 الأيقونة والشفافية

الصورة التي أرسلتها كانت محفوظة فعليًا بصيغة JPEG (رغم امتداد .png)، ولذلك لم تكن الخلفية شفافة حقًا — كانت شبكة الشطرنج الرمادية مرسومة كبكسلات حقيقية بدل شفافية فعلية.

قمت بمعالجة الصورة تقنيًا (كشف حدود الشكل تلقائيًا وفصله عن الخلفية) لإنتاج نسخة بخلفية شفافة 100% فعليًا (قناة Alpha حقيقية)، وهي المستخدمة الآن في:
- شاشة التحميل داخل التطبيق
- شعار القائمة الرئيسية
- أيقونة التطبيق على الهاتف (بكل الأحجام المطلوبة لأندرويد)

**بخصوص أيقونة الهاتف تحديدًا:** استخدمنا صيغة الأيقونة "الكلاسيكية" (وليست Adaptive Icon) لأنها الصيغة الوحيدة التي تحافظ على شفافية حقيقية تُظهر خلفية الهاتف من خلفها. هذا هو أفضل حل ممكن تقنيًا على أندرويد، لكن يجب العلم أن بعض واجهات المصنّعين (مثل بعض إصدارات One UI أو MIUI) قد تفرض شكلًا أو خلفية خاصة بها على الأيقونات القديمة رغم الشفافية — وهذا قيد من نظام أندرويد نفسه وليس من التطبيق.

## 🎵 الموسيقى

- الموسيقى المرفقة (`dwarven-mine.mp3`) مدمجة داخل التطبيق وتعمل بدون إنترنت.
- تتكرر تلقائيًا وباستمرار (`loop = true`) طالما هناك مقطع واحد فقط.
- إن أردت إضافة مقاطع أخرى لاحقًا لتُشغَّل بالتناوب: ضع الملفات في `www/assets/audio/`، ثم أضف مساراتها في المصفوفة `PLAYLIST` أعلى ملف `www/js/app.js` — سيبدأ التشغيل من الأول، ثم الذي يليه، وهكذا حتى يعود للأول تلقائيًا.
- تتوقف الموسيقى تلقائيًا عند دخول شاشة التحدي (لمساعدة اللاعب على التركيز)، وتعود عند الخروج منها.
- الصوت والتحكم بمستوى الصوت متاحان من زر "صوت" في القائمة الرئيسية، ويُحفظان محليًا على الجهاز.

## 🔢 قائمة الأرقام العشوائية

القائمة الكاملة (1351 رقمًا من 0.50 إلى 14.00) منسوخة **حرفيًا** كما أرسلتها دون أي تعديل، وتم التحقق آليًا من: عدم وجود تكرار، وأن كل رقمين متقابلين يجمعان 14.50، وأن التنسيق برقمين عشريين في كل رقم. نسخة مطابقة موجودة في `verify/numbers.txt` للمراجعة، وهي نفسها المُضمَّنة داخل `www/js/app.js`.

## 🕹️ قرار تصميمي بخصوص الجولات (يُرجى الانتباه)

الفكرة الأصلية لم تُحدّد بوضوح ماذا يحدث بعد أن يأخذ كل لاعب دوره مرة واحدة، فاعتمدت التصميم التالي:
- كل الجولة (لا كل لاعب) لها **رقم مستهدف واحد** يحاول جميع اللاعبين الوصول إليه بالتناوب.
- بعد أن يأخذ آخر لاعب دوره، تبدأ **جولة جديدة تلقائيًا** برقم عشوائي جديد، ويعود الدور للاعب الأول.
- يمكن لأي عدد من اللاعبين الحصول على نقطة في نفس الجولة إذا طابق كل منهم الرقم تمامًا.
- اللعبة تستمر بلا نهاية محددة إلى أن يضغط أحد على زر الخروج (أعلى يسار شاشة اللعب) ويؤكد الإنهاء.

إن كنت تريد آلية مختلفة (مثل عدد جولات محدد، أو نهاية معينة)، أخبرني وسأعدّلها بسهولة.

## 🧪 اختبار محلي سريع (اختياري)

المجلد `verify/` يحتوي اختبارين آليين شغّلتهما فعليًا للتأكد من سلامة كل تدفقات اللعبة (التنقل بين الشاشات، اختيار عدد اللاعبين، منطق التسجيل الدقيق للمطابقة التامة، الترتيب، الخروج). لتشغيلهما بنفسك بعد أي تعديل مستقبلي:

```bash
npm install --no-save jsdom
node verify/smoke_test.js
node verify/scoring_test.js
```

لمعاينة الواجهة سريعًا في متصفح الحاسوب (اختياري، فقط لتجربة التصميم قبل البناء):

```bash
npx serve www
```

## ⚙️ تخصيصات سريعة

- **تغيير اسم الحزمة (Package Name):** عدّل `appId` في `capacitor.config.json` قبل أول عملية بناء.
- **تغيير اسم التطبيق الظاهر:** عدّل `appName` في نفس الملف.
- **تغيير الألوان:** كل الألوان معرّفة كمتغيرات CSS في أعلى `www/css/style.css`.
